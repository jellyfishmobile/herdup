Put a team of AIs on your code.

herdup is a small desktop app that starts several AI coding agents on one project, side by side in a single terminal. Pick a folder, pick how much help you want, press start.

What it's for

Running one coding agent is easy. Running four — a lead splitting up the work, two writing code, one testing — means juggling terminals, remembering flags, answering the same trust prompt four times, and briefing each one by hand. People give up before they find out whether a team is actually better than a single agent.

herdup does that setup. It builds the layout, starts each agent, waits until each is genuinely at its prompt, and hands each one its instructions. Then it gets out of the way and gives you the terminal. It is a launcher, not a wrapper: once your team is running, herdup is not in the loop.

How it works

  1. Pick a project. A folder on your machine. If it has no version history, or uncommitted changes, herdup says so before anything starts — these agents edit files, and that should never be a surprise.
  2. Pick a team. Start from a size — one, two, four or six — then add or remove people. You see the shape of the workspace you're about to get before you get it.
  3. Press start. herdup creates the layout, starts each tool, waits for each to actually reach its prompt, and briefs it. About twenty seconds.
  4. Take the terminal. Your team is running in herdr. Start another project alongside it if you want; they run independently.

Requirements

herdr 0.8.2 or newer

herdup drives herdr, the terminal multiplexer that actually runs the agents. It must be installed and on your PATH. herdup checks the version and refuses to launch against anything older, because it relies on herdr's agent API.

At least one agent CLI

herdup starts tools you already have; it does not bundle or resell them. You need at least one of the tools listed below installed and signed in. Their subscriptions and API costs are between you and them.

git, strongly recommended

Not required, but these agents edit files. Without version history there is no undo, and herdup will warn you every time.

A terminal

Windows Terminal on Windows (PowerShell is used as a fallback), Terminal.app on macOS, or whatever x-terminal-emulator points at on Linux.

One deliberate limitation

herdup only types instructions into an agent unattended when it can reliably tell that the agent is at its prompt rather than sitting behind a dialog. For tools where that has not been verified, it holds the instructions and asks you to release them after a look. This exists because an early version fired a briefing into a tool that was showing a "trust this folder?" prompt, and the Enter keypress answered the dialog instead.

Installers are built by CI for each release. Nothing is code-signed yet, so Windows SmartScreen and macOS Gatekeeper will both warn you on first run.

Windows .msi installer or .exe setup tested macOS .dmg — Apple silicon and Intel built, not yet exercised Linux .deb and .AppImage built, not yet exercised

Honest status: herdup is developed and tested on Windows. The macOS and Linux installers are produced by the same CI from the same commit, but nobody has yet run them on a real desktop. If you try one, please say what happened.

Support

Bugs and questions

Open an issue on GitHub. Include your OS, your herdr version (herdr --version), and which tools were on the team.

It isn't finding my tool

herdup looks for each tool's binary on your PATH and tells you exactly what it looked for. If yours lives somewhere unusual, edit registry.toml rather than waiting for a release.

What herdup never does

It does not send your code anywhere, add a service between you and your tools, or require an account. The only thing that leaves your machine is an optional "create a GitHub repository" action you have to ask for.

herdup is an independent launcher for herdr and is not affiliated with herdr or with any of the agent tools listed above.
